# 集中アラーム (FocusAlarm)

Windows「クロック」アプリのフォーカスセッションと同じ考え方で集中時間を区切り、各セッションの終わりを**アラームのように**知らせるタイマーです。

Windows PowerShell 5.1 と WPF だけで動くので、インストールやコード署名は必要ありません。

## 特徴

- **合計時間を自動で分割**：休憩込みの合計時間（15〜240分）を決めると、1回あたり約21分の集中セッションと休憩に自動で振り分けます。内訳は画面にも表示されます。
- **休憩の設定**：休憩の有無と長さ（5分 / 10分 / 15分）を選べます。
- **自動で次へ**：次のセッションを自動で始めるかどうかを選べます。
- **アラーム**：セッションが終わると、最前面のアラームウィンドウを表示し、音をループ再生します。
  - 音は Windows 標準のアラーム音・着信音（`C:\Windows\Media` の `Alarm01`〜`Alarm10`、`Ring01`〜`Ring10`）から選べます。選ぶと数秒試聴できます。
  - 音量調整とスヌーズ（1分 / 5分 / 10分）にも対応しています。
  - デスクトップ通知（トースト）を一緒に出すこともできます。
- **操作**：開始・一時停止・再開・スキップ・リセット。残り時間はリング表示とウィンドウタイトルで確認できます。
- **多重起動しない**：すでに起動しているときは、メッセージを表示して終了します。

## 動作環境

- Windows 10 / 11
- Windows PowerShell 5.1（Windows に標準で入っています）

## 使い方

1. このリポジトリをダウンロードし、好きな場所に置きます。
2. `FocusAlarm.cmd` をダブルクリックすると起動します。
3. 必要なら `CreateShortcut.cmd` を実行すると、スタートメニューとデスクトップに「集中アラーム」のショートカットができます。同時に、ダウンロードしたファイルのブロックも解除されます。

ショートカットを削除するときは、PowerShell で次を実行します。

```powershell
.\CreateShortcut.ps1 -Remove
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `FocusAlarm.ps1` | アプリ本体 |
| `FocusAlarm.cmd` | 本体をウィンドウなしで起動するためのランチャー |
| `CreateShortcut.ps1` | スタートメニュー・デスクトップにショートカットを作成（`-Remove` で削除） |
| `CreateShortcut.cmd` | `CreateShortcut.ps1` をダブルクリックで実行するためのランチャー |

## 設定とログ

- 設定：`%APPDATA%\FocusAlarm\settings2.json`（変更すると自動で保存されます）
- エラーログ：`%APPDATA%\FocusAlarm\error.log`

## 開発メモ

`FocusAlarm.ps1` には日本語が含まれるため、**UTF-8（BOM 付き）**で保存してください。BOM がないと、Windows PowerShell 5.1 で文字化けして動きません。
